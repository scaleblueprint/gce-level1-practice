GOOGLE CERTIFIED EDUCATOR LEVEL 1

Know what to expect before exam day

This guide summarizes the current Google-published exam experience and the practical workflow you should be ready for.

Interactive exam37 + 337 multiple-choice questions + 3 lab scenarios3 hoursTotal exam window

1. Before the exam

  • Use the latest version of Google Chrome.
  • Have a working webcam available for the certification exam.
  • Make sure your internet connection and device are stable.
  • For the lab portion, Google recommends using an Incognito window; a remote browser session can be provided when needed.

2. Question section

  • Expect scenario-based multiple-choice questions rather than simple definitions.
  • Focus on choosing the most appropriate Google Workspace tool or setting for the classroom situation.
  • Pay attention to sharing roles, collaboration, organization, communication, and creation workflows.

3. Lab section

  • The interactive exam includes three lab-based scenarios.
  • Google provides an exam lab account or remote session for completing the tasks.
  • You perform actual Workspace actions from the instructions, so knowing where settings live matters as much as knowing the terminology.

Exam-day workflow

01Read the whole scenarioUnderstand the final outcome before clicking around.
02Notice exact requirementsNames, permissions, dates, recurrence, labels and file locations matter.
03Complete the Workspace actionsWork methodically and verify the requested setting before moving on.
04Manage your timeThe interactive exam gives three hours for both the questions and labs together.

After the exam

Google says pass/fail results are normally emailed within three business days. If a candidate does not pass, the published retake waiting period is eight days. Level 1 certification is valid for 36 months.

Our mock scores are practice indicators only; they are not Google's official scoring formula.

Language note

Google currently documents two Level 1 exam experiences depending on language. The interactive experience is 37 multiple-choice questions + 3 lab scenarios in 3 hours. A multiple-choice-only experience in some languages is 37 questions in 2 hours.

STUDY MATERIALS

Level 1 skills you should be able to perform without help

Use these concise revision notes before attempting the timed mocks. The focus is on practical classroom decisions and common Workspace workflows.

Recommended order

Drive & sharing→Docs & Slides→Classroom→Gmail→Calendar & Meet→Forms & Sheets
01
Google Drive & sharingOrganize files and give the right people the right access.

Know this

Viewer can read, Commenter can leave feedback without directly changing content, and Editor can modify the file. Prefer Restricted sharing for material intended only for named people.

Be able to do

  • Create and organize folders and files.
  • Share a file with specific people and change their role.
  • Remove someone's access.
  • Search Drive and use clear file/folder names.
  • Use shortcuts where useful instead of creating unnecessary duplicates.
Exam habit: ask “Does this person need to view, comment, or edit?” before choosing a permission.
02
Docs & Slides collaborationWork together without losing control of the original.

Know this

Comments are for discussion and feedback. Suggesting mode lets someone propose edits that can be accepted or rejected. Version history helps identify changes and restore earlier content.

Be able to do

  • Add and resolve comments.
  • Use @mentions to direct feedback.
  • Use Suggesting mode.
  • Open version history and understand why it is useful.
  • Use heading styles to structure a long Doc.
03
Google ClassroomChoose the correct post type and assignment settings.

Know the difference

Assignment = students submit work. Material = resource only. Announcement = class update. When attaching a template, “Make a copy for each student” gives every learner an individual editable copy.

Be able to do

  • Create and schedule assignments.
  • Set due dates and clear instructions.
  • Attach Drive files with the correct student permission.
  • Post materials and announcements.
  • Recognize when a task should not be an assignment.
04
GmailFind messages quickly and organize them automatically.

Useful search operators

from:person@example.comhas:attachmentfilename:pdf

Be able to do

  • Create labels.
  • Create filters that automatically apply labels.
  • Combine search operators to narrow results.
  • Write useful subject lines and concise messages.
Example: from:principal@school.org has:attachment finds messages from that sender that include attachments.
05
Calendar & Google MeetSchedule communication clearly and accessibly.

Be able to do

  • Create an event and invite guests.
  • Make an event recur weekly or on another schedule.
  • Add Google Meet conferencing.
  • Include useful context or an agenda in the event description.
  • Use Meet captions when they support participant accessibility.
Scenario clue: if the need involves a date, recurrence, guests and a video meeting, think Calendar + Meet together.
06
Google FormsCollect structured information and build simple quizzes.

Be able to do

  • Create a Form and choose suitable question types.
  • Mark important questions Required.
  • Turn on quiz mode and configure answer keys/points where appropriate.
  • Use paragraph, multiple-choice, scale and other question types appropriately.
  • Send Form responses to Sheets for further analysis.
07
Google SheetsSort, filter, calculate and visualize response data.

Be able to do

  • Sort a full data range while keeping rows together.
  • Filter data without deleting rows.
  • Use a simple function such as AVERAGE.
  • Create a suitable chart for category comparisons.
  • Recognize when Forms response data should be analyzed in Sheets.
Avoid sorting only one column when the surrounding row data must remain aligned.
08
Sites, accessibility & cross-tool decisionsChoose the simplest tool that fits the educational outcome.

Know this

Google Sites is suitable for a simple information site with pages and embedded resources. Accessibility choices such as readable structure, captions and clear instructions help more learners participate.

Practice deciding

  • Site for a simple published information hub.
  • Docs for collaborative writing.
  • Slides for collaborative presentations.
  • Forms for structured collection.
  • Sheets for data analysis.
  • Calendar/Meet for scheduled live communication.
